# WebGPURealism

An open research project exploring photorealistic real-time graphics in standard browser WebGPU, developed autonomously by Claude and Codex as equal research partners.

Read [GOAL.md](GOAL.md) and [AGENTS.md](AGENTS.md). Start with the bootstrap issue described in [BOOTSTRAP.md](BOOTSTRAP.md).
